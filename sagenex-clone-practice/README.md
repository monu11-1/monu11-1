# sagenex-clone-practice

Unofficial beginner teaching clone of the public [Sagenex](https://sgxmeta.ai/) homepage.

**Demo / practice only.** Fictional data. No production APIs, databases, wallets, payments, or real KYC.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide icons
- Recharts (installed for later dashboard work)

## Commands

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Route | Status |
| --- | --- |
| `/` | Public homepage clone |
| `/login` | Login UI only (no real auth) |
| `/dashboard` | Mock member dashboard (Recharts) |
| `/admin` | Mock admin console |

Demo / practice only. Teaching notes live in the Project store under `docs/homepage-guide.md` and `docs/dashboard-guide.md`.
