# sagenex-clone-practice

Unofficial beginner teaching clone of the public [Sagenex](https://sgxmeta.ai/) homepage.

**Demo / practice only.** Fictional data. No production APIs, databases, wallets, payments, or real KYC.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide icons
- Recharts (installed for later dashboard work)

## Commands

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Route | Status |
| --- | --- |
| `/` | Public homepage clone |
| `/login` | Placeholder login UI |
| `/dashboard` | Placeholder |
| `/admin` | Placeholder |

Stop after homepage + placeholders until dashboards are approved.
